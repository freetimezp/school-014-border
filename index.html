02 / THE CODE

One property.
Four personalities.

The border-style property controls how the line around an element is rendered. It works together with border width and color.

✳

A border needs a visible style. Without one, its default style is none.

styles.css 
.card {
  border-width: 4px;
  border-style: dashed;
  border-color: #4477E8;
}
